# Wetterkurve

## Tagline

A compact three-day weather chart for up to three locations.

## Description

Wetterkurve adds current weather and temperature to the GNOME top panel. Open
the menu for a clear three-day view: temperature and feels-like curves,
precipitation probability, precipitation amount, and a weekday strip make the
forecast easy to read at a glance.

Save up to three locations, switch between them in the popup, or search for a
new location without leaving GNOME. The extension refreshes automatically every
20 minutes and can be refreshed manually at any time.

Weather forecasts and location search are provided directly by Open-Meteo. No
API key or account is required.
